# Zoo Game — Patch de acessibilidade APAE

Este patch adiciona uma camada de acessibilidade e onboarding inspirada nos jogos-modelo analisados.

Implementado:
- tutorial visual e preparado para narração;
- tutorial mostrado automaticamente na primeira vez;
- botão “Como jogar” no menu;
- opção para pular tutorial;
- opção para repetir instruções;
- leitura preparada para animais, sílabas e botões;
- controle de volume;
- progresso visual;
- feedback gentil de acerto/erro;
- tentativa ilimitada após erro;
- tela final com confetes;
- botões de reiniciar e voltar ao menu;
- arquitetura de áudio que não quebra o jogo quando os arquivos ainda não existem.

Ainda depende de recursos externos:
- arquivos de narração humana/TTS;
- música, se desejada;
- integração com a plataforma da APAE/Nino Edu, caso seja exigida;
- eventual intro institucional, caso vocês recebam o asset e autorização de uso.
